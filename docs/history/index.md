## Como usar

- Consulte a data, o commit e o ambiente citados antes de usar um resultado.
- Um achado arquivado não está automaticamente resolvido. O roadmap registra pendências
  reavaliadas; outros achados exigem confronto com o código atual.
- Afirmações como “ainda não implementado”, “normativo” ou “publicação bloqueada” no
  corpo original pertencem ao momento daquele documento. Não autorizam nem impedem uma
  operação atual por si sós.
- Requisitos e contratos ainda úteis foram mantidos nos guias atuais. Os originais
  continuam aqui como evidência, com referências ajustadas para seus destinos.
- O pequeno `plan.md` da raiz é apenas um apontador para compatibilidade com referências
  anteriores; o ponto de entrada atual é o README do projeto.
